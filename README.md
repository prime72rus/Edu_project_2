# EDU_PROJECT_2
Курсовая работа — это возможность закрепить знания из модуля и написать полноценный проект, который можно добавить в портфолио.
# Задание
Написать программу, которая будет получать информацию о вакансиях с платформы hh.ru в России, сохранять ее в файл и позволять удобно работать с ней: добавлять, фильтровать, удалять.

# Структура проекта
## Модуль base_api.py
Содержит абстрактный класс для работы с API сервиса с вакансиями.
## Модуль base_saver.py
Содержит абстрактный класс, который обязывает реализовать методы для добавления вакансий в файл, получения данных из файла и удаления информации о вакансиях. 
## Модуль exceptions.py
Содержит пользовательские исключения
## Модуль external_api_hh.py
Содержит класс, наследующийся от абстрактного класса, для работы с платформой hh.ru. Класс имеет методы для подключения к API и получения вакансии.
## Модуль json_saver.py
Содержит класс для работы с JSON-файлом: загрузка данных из файла, сохранение данных в файл с перезаписью и без, добавление вакансии в файл, удаление вакансии из файла, конвертации списка объектов класса Vacancy в список словарей
## Модуль utils.py
Содержит функции для реализации пользовательского интерфейса
## Модуль vacancies.py
Содержит класс для работы с вакансиями. Класс имеет возможности для поддержки методов сравнения вакансий между собой по зарплате. Данные перед инициализацией атрибутов объекта класса проходят валидацию.
## Модуль config.py
Содержит пользовательские настройки для приложения: путь к каталогу файла vacancies.json
## Модуль main.py
Главный модуль запуска программы. Содержит функцию пользовательского интерфейса.
